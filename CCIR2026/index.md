# <i class="fas fa-feather-alt"></i>第三十二届全国信息检索学术会议

在数据爆炸与人工智能崛起的时代浪潮中，信息检索正经历着前所未有的变革。全国信息检索学术会议（CCIR）是由中国中文信息学会（CIPS）举办的权威学术会议，持续聚焦前沿研究，推动了相关技术及互联网产业的发展，更是顶尖学者、行业精英交流思想、激发创新的核心平台。今年，CCIR 2026将于8月14日走进"北国春城"——吉林长春，在净月潭畔的夏日清风中，开启一场关于信息检索前沿的深度对话。本次大会由中国中文信息学会信息检索专委会主办，吉林大学承办。本次大会的主题是"AI for Science: 新范式与新未来"，聚焦科学信息检索与前沿科学研究的交叉融合，致力于构建海量知识检索、数据驱动、机理融合与智能发现的科研新范式。会议包含一系列学术活动，除传统的海内外知名学者的大会报告、会议论文报告外，还将组织青年学者论坛以及面向热点研究问题的讲习班等。
